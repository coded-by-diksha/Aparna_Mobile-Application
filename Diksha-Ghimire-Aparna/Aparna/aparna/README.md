# aparna-frontEnd

This is the mobile application that is built to track the upcoming period cycle of a lady by analyzing the past cycles. This application is made using Flutter as the frontend integrating with node and PostgreSQL.

## Features

- User authentication and login
- Period cycle tracking
- Human verification with CAPTCHA
- Beautiful gradient UI with consistent theming
